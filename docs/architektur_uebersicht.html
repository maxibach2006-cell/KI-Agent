Teil 1 · 1D-Simulation

Eine Frage auf der Strecke

Die Daten werden vor den Fragen eingelesen (Phase A): lokal per Befehl oder Button, auf dem Server beim ersten Öffnen der App und danach regelmäßig im Hintergrund. Jede Frage durchläuft dieselbe Strecke (Phase B). Wähle eine Beispielfrage und gehe Schritt für Schritt durch. Werte und Zeiten stammen aus den Testläufen.

Teil 2 · Entscheidungsbaum

Wie das System gewachsen ist

Von links nach rechts: Version, Bereich, Entscheidung und die Wege, die dabei verworfen wurden. Der Balken zeigt den Umfang einer Version. Ein Klick klappt auf und zeigt die Begründung.

Teil 3 · Lernkurve

Was die Korrekturen gebracht haben

Zwei Messgrößen über die Entwicklung hinweg. Rote Punkte markieren Verschlechterungen durch einen Irrweg.

Lokal: Ollama (qwen2.5:7b, bge-m3), ChromaDB, Streamlit. Datenzugang: Microsoft Graph (delegiert) oder Demo-Daten. Quellcode und Details: README.md im Projektordner.
